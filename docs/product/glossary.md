# Product glossary

| Term | Meaning |
| --- | --- |
| Capability | A repeatable problem the manufacturer can solve, supported by evidence and constraints |
| Prospective account | A company that matches the target profile but has not yet presented a qualified need |
| Opportunity signal | Evidence that an account may have a relevant operational or commercial need |
| Capability match | A recorded hypothesis connecting a signal or known need to a capability |
| Engagement | A focused interaction intended to validate a capability match |
| Inquiry | An inbound request or an outbound-discovered need requiring qualification |
| Qualified need | A real, relevant problem worth consuming technical-discovery effort |
| Technical discovery | Collection of commercial, process, machine, product, and constraint information |
| Engineering-ready | A qualified opportunity whose required context and evidence are complete enough for engineering review |

Do not use `lead`, `prospect`, and `inquiry` interchangeably. Prefer `prospective account` for the company and `inquiry` for the expressed or discovered need.
