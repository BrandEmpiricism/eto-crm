# Reference lifecycle

1. Capability defined
2. Target market selected
3. Prospective account identified
4. Opportunity signal captured
5. Capability matched
6. Engagement initiated
7. Interest or need discovered
8. Need qualified
9. Technical discovery
10. Feasibility review
11. Engineering-ready
12. Solution and estimation
13. Quotation
14. Customer decision

The initial release supports the early lifecycle through a manual capability match. Prospect discovery, enrichment, outreach automation, and scoring are later phases.
